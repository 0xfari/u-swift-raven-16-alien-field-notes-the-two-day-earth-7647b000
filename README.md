A judge model compares the lines two at a time on the alien's one-line review of Earth first, then funniness, originality, whether it reads like a real review, and how tight the writing is. Free entry, $2 pool over the top ten ($0.63 / $0.43 / $0.30 / ...). Entries close 2026-11-26 18:55 WIB; blind rounds (next round cutoff 2026-11-25T01:40:22Z), results due 2026-12-18.
